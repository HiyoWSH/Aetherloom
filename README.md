# Aetherloom · 以太织机

> 织机不发声，只记住经纬。

中文 | [English](README.en.md)

这里放的是它的织纹：一份份文件，写清「何时、用哪条纹样、水到几分」。

## 织纹的模样

`weaves/patterns/` 下的 `.txt`，一针一行，三样东西，用竖线隔开：

```
刻度|纹样|振幅
```

```text
00:00|1|0
00:04|1|20
00:09|1|40
00:14|1|60
00:19|1|40
00:24|1|20
00:30|1|0
```

| 一针 | 写什么 | 可取什么 |
|---|---|---|
| 刻度 | 从零起算的时刻 | `12`、`12.5`、`01:12`、`00:01:12`，最远三小时 |
| 纹样 | 走哪条波形 | `1`–`10` 的整数 |
| 振幅 | 水到几分 | `0`–`100` 的整数，`0` 为涸 |

落针的五条铁律：

- 三样必须齐全，缺一样这一针就作废。
- 两针之间不近于 0.5 秒，更密的会被节流吞掉。
- 刻度递增最稳；同一刻落两针，只认后一针。
- `#` 起首的整行是旁注，不能缀在针脚末尾。
- 末针振幅归零，否则织机停在最后一针上不走。

## 十种纹样

| 编号 | 纹样 | 形态 | 宜用在 |
|---|---|---|---|
| 1 | 静流 | 平铺的持续，三档里最轻 | 铺底、收尾、长久的低处 |
| 2 | 常流 | 与静流同一条波形，中档 | 常规律动的主力 |
| 3 | 奔流 | 与静流同一条波形，满档 | 顶点、满水 |
| 4 | 疏雨 | 短促点触，间隙分明 | 鼓点、清脆的节奏 |
| 5 | 退潮 | 一串脉冲，一次比一次弱 | 由快到慢、收束 |
| 6 | 回流 | 快慢自循环，周期最长 | 段落转折、变速的曲子 |
| 7 | 骤雨 | 高密度短脉冲，连成一片 | 强节奏的副歌 |
| 8 | 攀藤 | 幅度一级级往上爬 | 渐强、爬坡 |
| 9 | 呼吸 | 一长一短，交替而来 | 长短对比、留白 |
| 10 | 连珠 | 短击连成一串 | 密集连击、沸点之前 |

静流、常流、奔流本是同一条波形，只是内置了三档深浅。想要「同一手感、只是强弱不同」，定住一条纹样去调振幅即可，不必在这三条之间来回换。四到十才是形状真正不同的纹样。

## 五档水势

| 振幅 | 水势 | 宜用在 |
|---|---|---|
| `0` | 涸 | 起手、段落收口、收尾 |
| `1`–`20` | 涓 | 铺垫、间歇 |
| `21`–`50` | 漾 | 常规律动的主体 |
| `51`–`80` | 涌 | 副歌、峰值前段 |
| `81`–`100` | 沸 | 峰值、顶点 |

相邻两档差不出五，写五或十的倍数就够了。

## 库藏

| 目录 | 收什么 | 文件 |
|---|---|---|
| `weaves/patterns/` | 文本织纹，一针三列 | `.txt` |
| `weaves/pulse-patterns/` | 脉冲织纹，单件或整包 | `.pulse`、`.zip` |

两种织纹各自成文，格式互不通用。整包以 `.zip` 收入，包名与单件同名。
